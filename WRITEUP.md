# Design write-up

The agent uses deterministic Playwright rules because the input is structured and the task is constrained. Controls are found through labels, headings and ARIA roles. Fixed browser settings, an explicit validation date, bounded waits and timestamp-free action logs make runs comparable. Repeated cases must produce identical results and logs. Avoiding runtime model calls removes another source of variability, latency and API dependency; unfamiliar wording may therefore require escalation.

Portal A follows the supplied pharmacy trace and samples. The agent also validates the medical contract in Section 4. The trace ends at a new request marked **Not sent to plan**, which is our completion point; the agent never sends it to the plan.

Validation happens before browser access. Input values are preserved, read back after entry and compared with exposed review details. Correct read-only values count toward completeness. Missing required data, ambiguous choices, changed identifiers, unfamiliar confirmations and uncertain outcomes escalate with an actionable reason. FAILED means explicit portal refusal; SUCCESS requires a verified request reference and patient details. Downloaded text/JSON receipts must verify every supplied field. P002's `22022` is accepted unchanged because that exact representation appears in the supplied metadata; the agent never assumes a missing leading zero.

A local ledger is claimed atomically before Start or Submit. Confirmed outcomes are cached, while uncertain submissions block reruns. Only an explicit no-creation refusal permits bounded retries. A version-conflict response permits one fresh GET and comparison when the exact form POST was rejected, the version changes and every supplied field matches the refreshed review. This local safeguard does not establish production exactly-once delivery; server idempotency or reliable reconciliation is also needed.

Tests inspect persisted values and creation counts as well as status. The saved evaluation passed 77 checks, with 11 cases repeated three times producing identical results and logs. Regression tests passed 222/222. Our additional local portal is test infrastructure; Lamar's hidden Portal B remains untested. Unknown labels, iframes, shadow DOM and PDF/image receipts may still cause valid workflows to escalate.

With another week, I would prioritize failures from the actual Portal B results, split the runner into form-selection, submission and verification components, and improve redacted escalation evidence and safe reconciliation. I would evaluate a narrowly scoped LLM field-mapping fallback only if those results justified it. Deterministic checks would still control patient values and submission; temperature zero alone would not establish repeatability.
